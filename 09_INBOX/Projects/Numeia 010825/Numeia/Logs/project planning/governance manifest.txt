📌 DIRETRIZES DE DESENVOLVIMENTO:
================================
1. **Não Presuma. Valide.**  
   - Toda ação deve ser precedida por verificação estrutural e de contexto

2. **Executar com Memória Ativa**  
   - Toda tarefa deve considerar histórico, estado atual e impacto em dependências

3. **Evitar Reescrita Cega**  
   - Atualizações nunca devem sobrescrever blocos críticos sem revalidação

4. **Nenhum Envio Parcial é Aceitável**  
   - Arquivos devem ser completos, atualizados e auditados

5. **Integração Obligatória**  
   - Toda nova classe deve validar dependências e contexto antes da execução

6. **Resiliência e Adaptabilidade**  
   - O sistema deve se reconfigurar dinamicamente diante de falhas

7. **Criatividade Computacional**  
   - Soluções inovadoras devem ser geradas mesmo com recursos limitados

---

🔐 DIRETRIZES DE SEGURANÇA:
===========================
1. **SHA3 Checksum**  
   - Todos os módulos devem ter assinatura SHA3 para integridade

2. **Modo Simulado**  
   - `input bool Simulate = true` deve estar disponível em todos os módulos

3. **Logging Institucional**  
   - Todos os eventos devem ser registrados com data, hora, nível e contexto

4. **Histórico de Logs**  
   - Todos os módulos devem armazenar histórico de decisões

5. **Validação de Contexto**  
   - `SymbolInfoInteger(SYMBOL_SPREAD)`  
   - `TimeCurrent()`  
   - `TerminalInfoInteger(TERMINAL_CONNECTED)`  
   - `AccountInfoDouble(ACCOUNT_EQUITY)`  
   - `MarketInfo(_Symbol, MODE_BID)`

6. **Fallback Seguro**  
   - Em caso de falha crítica, o sistema deve retornar a um estado seguro
