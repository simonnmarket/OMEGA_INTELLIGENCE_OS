## 🎯 FLUXO DE EXECUÇÃO COMPLETO

### **CICLO DE TRADING (run_complete_cycle)**

```python
1. DATA FETCHING
   └─> UnifiedDataFetcher.fetch_all_market_data()
       ├─> yfinance: Equities, Forex, Gold spot, Futures spot
       ├─> FRED: Macro (rates, inflation, geo risk)
       └─> ccxt: Crypto (BTC, ETH, exchanges)
       
2. SIGNAL GENERATION
   └─> Para cada módulo:
       ├─> CryptoModule.analyze(...engines...)
       ├─> ForexModule.analyze(...engines...)
       ├─> GoldModule.analyze(...engines...)
       └─> FuturesModule.analyze(...engines...)
       
3. CONFLICT DETECTION
   └─> CorrelationAnalyzer.detect_conflicts(all_signals)
       ├─> Correlação positiva + direções opostas → CONFLITO
       └─> Correlação negativa + mesma direção → CONFLITO
       
4. CAPITAL PRIORITIZATION
   └─> GlobalCapitalManager.prioritize_signals(signals)
       ├─> Ordenar por confidence
       ├─> Aprovar até limite de capital por módulo
       └─> Rejeitar excedentes
       
5. RISK CHECK
   └─> GlobalKillSwitch.check_and_trigger(current_capital)
       ├─> DD total >= 15% → SHUTDOWN
       ├─> Daily loss >= 3% → SHUTDOWN
       └─> Se OK → Prosseguir
       
6. EXECUTION
   └─> ExecutionRouter.route_and_execute(signal)
       ├─> Forex → MetaTrader 5
       ├─> Crypto → Binance (ccxt)
       ├─> Equities/Gold → Interactive Brokers
       └─> Futures Synthetic → Position Tracker

7. MONITORING
   └─> PerformanceTracker.update_metrics()
       ├─> P&L por módulo
       ├─> Sharpe Ratio
       ├─> Drawdown atual
       └─> Correlation matrix
```
