- Agora usa OnTimer() para verificar a cada 1 segundo

====================================================================
PASSO A PASSO PARA RECOMPILAR
====================================================================

1. ABRIR METAEDITOR
   - No MT5, pressione F4
   - Ou: Menu Tools → MetaQuotes Language Editor

2. ABRIR O ARQUIVO
   - No painel Navigator (esquerda)
   - Experts → SamsungGlobalMarket_EA.mq5
   - Duplo clique

3. VERIFICAR VERSÃO
   - Linha 80 deve mostrar:
     Print("Versao: 1.01");
   - Se mostrar 1.00, o arquivo errado está aberto!

4. COMPILAR
   - Pressione F7
   - Ou: Menu Compile → Compile
   - Aguarde: "0 error(s), 0 warning(s)"

5. VERIFICAR COMPILAÇÃO
   - Aba Toolbox (parte inferior)
   - Deve aparecer:
     "SamsungGlobalMarket_EA.ex5 generated"

6. FECHAR METAEDITOR
   - Alt+F4 ou X

7. REINICIAR EA NO MT5
   - Remover EA do gráfico (clicar com direito → EA → Remove)
   - Anexar EA novamente (arrastar do Navigator)
