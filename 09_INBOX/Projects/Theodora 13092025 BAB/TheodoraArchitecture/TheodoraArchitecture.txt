├── Config/                -> Configurações e inputs
├── Core/                  -> Núcleo do sistema (brain, blockchain, force)
├── Data/                  -> Leitura e processamento de dados de mercado
├── DecisionEngine/        -> Motor de decisão quântica (Heisenberg, Bohr, Planck)
├── Detection/             -> Detecção de padrões/eventos
├── Execution/             -> Primitivos de execução
├── ExecutionLogic/        -> Lógica de execução, gerenciamento de ordens
├── Integration/           -> Conexão com APIs, nuvem, Telegram, Alibaba
├── Intelligence/          -> IA, redes neurais, aprendizado quântico
├── Math/                  -> Matemática aplicada (ex: Alglib/)
├── Neural/                -> Núcleos neurais
├── Optimization/          -> Otimização e parâmetros
├── Quantum/               -> Componentes quânticos
├── Risk/                  -> Gestão de risco institucional
├── Security/              -> Firewall quântico, blindagem SHA3, safe mode
├── Signals/               -> Enumerações e sinais
├── Templates/             -> Modelos reutilizáveis
└── Utils/                 -> Funções auxiliares puras (sem efeitos colaterais)
