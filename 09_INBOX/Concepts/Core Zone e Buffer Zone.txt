Resumo da estrutura:

Linha 1 – Core Zone (Inferior): onde começa o movimento.

Linha 2 – Buffer Zone (Inferior): zona de observação/espera.

Linha 3 – Core Zone (Intermediário): nova possibilidade de decisão.

Linha 4 – Buffer Zone (Superior): novamente zona de incerteza.

Linha 5 – Core Zone (Superior): zona crítica para novo ciclo ou reversão.

O foguete (representando o preço ou um movimento relevante) atravessa essas camadas, e cada transição tem um significado tático.

Modelo em Python (Console Simulation)
# Definição das zonas
zones = [
    {"linha": 1, "tipo": "CORE", "nome": "CORE ZONE INFERIOR", "acao": "Decisão inicial"},
    {"linha": 2, "tipo": "BUFFER", "nome": "BUFFER ZONE INFERIOR", "acao": "Aguardar comportamento"},
    {"linha": 3, "tipo": "CORE", "nome": "CORE ZONE INTERMEDIÁRIA", "acao": "Nova decisão possível"},
    {"linha": 4, "tipo": "BUFFER", "nome": "BUFFER ZONE SUPERIOR", "acao": "Aguardar comportamento"},
    {"linha": 5, "tipo": "CORE", "nome": "CORE ZONE SUPERIOR", "acao": "Novo ciclo ou reversão"}
]

# Estado do foguete
rocket_position = 1

def mostrar_zonas(posicao_foguete):
    print("\n=== Estrutura de Zonas ===\n")
    for zone in reversed(zones):
        linha = zone["linha"]
        marca_foguete = " <-- FOGUETE" if linha == posicao_foguete else ""
        print(f"[LINHA {linha}] - {zone['nome']} ({zone['tipo']}){marca_foguete}")
        print(f" Ação: {zone['acao']}\n")

def mover_foguete():
    global rocket_position
    if rocket_position < 5:
        rocket_position += 1
        print("\nFoguete subiu uma camada!")
    else:
        print("\nFoguete já está no topo!")

# Simulação simples
mostrar_zonas(rocket_position)

# Mover o foguete
for _ in range(4):
    input("Pressione Enter para subir...")
    mover_foguete()
    mostrar_zonas(rocket_position)
