INSTALAÇÃO E CONFIGURAÇÃO
-------------------------

PRÉ-REQUISITOS:
- Python 3.8+
- 16GB RAM mínimo
- SSD NVMe para latência
- Conexão internet estável (< 10ms latency)

DEPENDÊNCIAS:
numpy>=1.21.0
pandas>=1.3.0
scipy>=1.7.0

INSTALAÇÃO:
1. git clone https://github.com/numeia/trading-system-tier0.git
2. cd trading-system-tier0
3. pip install -r requirements.txt
4. python sistema_numeia_trading.py
