✅ MODELO DE CARRY RETURN: APROVADO
• Conceito: O carry return é o componente mais importante para arbitragem de term structure.
• Formulação: `Carry = (F2/F1) - 1.0) * (T2 - T1) / (T2 - T1)
• Implementação: O motor `_calculate_carry_return` calcula o carry return com base nos preços de futuros, essencial para a avaliação de lucro teórico.
• Validação: Garante que o lucro teórico não seja anulado por custos de transação e custos de carry.
• Validação: A estratégia agora filtra oportunidades onde o carry return é favorável, aumentando a robustez a longo prazo.
