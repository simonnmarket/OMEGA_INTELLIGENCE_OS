Ajustes Dinâmicos:
• Accuracy > 60%: +10% no peso
• Accuracy < 40%: -10% no peso
• Circuit breaker ativo: peso = 0.0

## 🎯 SISTEMA DE CONSENSO

### CÁLCULO DE CONSENSO:
Passos:

Coletar votos válidos (excluir NO_VOTE e technical_error)

Aplicar pesos a cada voto

Calcular scores ponderados por direção (BUY/SELL/HOLD)

Determinar direção vencedora (maior score)

Verificar threshold mínimo (28.6%/42.9%/57.1%)

Retornar decisão final

Fórmula:
Score(BUY) = Σ(confiança_agente_i × peso_agente_i) ∀ voto_i = BUY
Consenso% = Score(vencedor) / Σ(pesos_todos_votos)

# Script de alerta (rodar via cron a cada 1 minuto)
ALERT_FILE="$WORKDIR/logs/alerts.log"

# Verificar condições críticas
check_conditions() {
    # 1. Dashboard offline
    if ! curl -s http://localhost:8501/_stcore/health | grep -q "ok"; then
        echo "$(date) - ❌ DASHBOARD OFFLINE" >> "$ALERT_FILE"
    fi
    
    # 2. Mais de 5 erros nos últimos 5 minutos
    ERROR_COUNT=$(tail -1000 "$WORKDIR/logs/system.log" | grep -c "ERROR\|CRITICAL")
    if [ $ERROR_COUNT -gt 5 ]; then
        echo "$(date) - ⚠️ MUITOS ERROS: $ERROR_COUNT" >> "$ALERT_FILE"
    fi
    
    # 3. Nenhum trade nas últimas 2 horas
    LAST_TRADE=$(find "$WORKDIR/logs" -name "*executions*.csv" -exec tail -1 {} \; 2>/dev/null | cut -d',' -f1)
    if [ ! -z "$LAST_TRADE" ]; then
        LAST_TRADE_TIME=$(date -d "$LAST_TRADE" +%s)
        CURRENT_TIME=$(date +%s)
        if [ $((CURRENT_TIME - LAST_TRADE_TIME)) -gt 7200 ]; then  # 2 horas
            echo "$(date) - ⚠️ SEM TRADES POR 2 HORAS" >> "$ALERT_FILE"
        fi
    fi
}
